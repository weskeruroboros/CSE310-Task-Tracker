# Overview

This software is a lightweight command-line script that outputs a customized greeting to verify that the local environment and execution pipeline are properly configured.

The purpose of creating this software is to establish a working baseline project, test terminal execution, and practice version control integration before building more complex full-stack applications.

[Software Demo Video](https://youtu.be/YXcj0y_rtZM)

# Development Environment

* **Tools:** Visual Studio Code with the Python extension, Windows PowerShell terminal, and Git for version control.
* **Language:** Python 3.14.7, an interpreted, high-level programming language used to execute the command-line script.
